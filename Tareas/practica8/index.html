¡Bienvenido al Chatbot del Estatuto Orgánico!

Este chatbot ha sido desarrollado para asistirte en todo lo relacionado con la normativa interna, historia, símbolos y estructura de la Universidad Autónoma de Santo Domingo (UASD).

Puedes empezar de la siguiente forma:

  • Selecciona una de las 35 preguntas sugeridas en el panel izquierdo.
  • Escribe tu propia pregunta en la barra inferior (ejemplo: "¿Cuántos vicerrectores tiene la UASD?").
  • Configura tu Gemini API Key (en el engranaje arriba a la derecha) para tener respuestas inteligentes y libres ilimitadas.

Configuración de IA

Para conectar el chatbot con la inteligencia artificial de Google Gemini y hacer preguntas de manera libre y fluida, introduce tu clave de API (API Key) a continuación.

La clave se guarda localmente en tu navegador y no se envía a servidores externos aparte de la API oficial de Google.

Cómo obtener una API Key gratuita:

  1. Visita Google AI Studio e inicia sesión con tu cuenta de Google.
  2. Presiona el botón "Get API key" en la parte superior izquierda.
  3. Selecciona "Create API key" y elige "Create API key in new project".
  4. Copia la clave generada (empieza por AIzaSy...) y pégala abajo.
